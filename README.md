REVANHDYH/BAILEYS

REVANHDYH/BAILEYS adalah library berbasis TypeScript dan WebSocket untuk berinteraksi dengan WhatsApp Web API.

Project ini merupakan pengembangan dari "WhiskeySockets/Baileys" (https://github.com/WhiskeySockets/Baileys), dengan tetap mempertahankan atribusi kepada project aslinya.

⚠️ Penafian

REVANHDYH/BAILEYS merupakan project independen dan tidak berafiliasi, tidak disponsori, tidak disahkan, serta tidak memiliki hubungan resmi dengan WhatsApp maupun perusahaan afiliasinya.

WhatsApp adalah merek dagang terdaftar milik pemegang haknya masing-masing.

Pengelola project tidak mendukung penggunaan library ini untuk aktivitas yang melanggar Ketentuan Layanan WhatsApp.

Pengguna bertanggung jawab atas segala aktivitas yang dilakukan menggunakan library ini.

Harap gunakan library secara bijak dan bertanggung jawab.

Kami tidak menganjurkan:

- Pengiriman spam kepada pengguna lain.
- Pengiriman pesan massal yang mengganggu.
- Penggunaan untuk aktivitas penguntitan atau pengawasan tanpa izin.
- Aktivitas otomatisasi yang melanggar ketentuan layanan WhatsApp.

Gunakan project ini atas risiko dan tanggung jawab masing-masing.
